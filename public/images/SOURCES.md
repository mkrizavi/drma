# Photography sources

The homepage hero, homepage property-care section and Über uns photo are displayed from Unsplash's image CDN and are marked free to use under the [Unsplash License](https://unsplash.com/license). They illustrate property environments; they do not depict DRMA projects, staff, or Munich locations. Source links and photographer credits are maintained in `src/lib/photos.ts`. All eight service visuals are original SVG code in `src/components/service-illustration.tsx`.

The owner's casual portrait is not displayed in V5. The earlier derived file remains recoverable from commit `6705e6f`; it is not included in the current public assets.
